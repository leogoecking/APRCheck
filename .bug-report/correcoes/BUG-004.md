# BUG-004

## Root cause

A interface já havia sido migrada para comparação mensal, mas a rota `POST /comparisons/run/{batch_id}` continuava ativa e ainda gerava novas execuções com `scope_type = 'batch'`.

## Files changed

- `app/routers/comparisons.py`
- `tests/test_routes.py`

## Exact fix applied

- A rota operacional por lote deixou de criar `ComparisonRun` novo.
- O endpoint agora redireciona de volta para a tela de importações com mensagem orientando o uso da comparação por competência.
- A suíte foi ajustada para tratar a comparação mensal como fluxo principal.

## Regression risk considered

Baixo. A mudança bloqueia apenas a criação operacional de novas comparações por lote, preservando compatibilidade com dados históricos já existentes.

## How to validate

- Executar `.venv/bin/pytest`
- Tentar acessar `POST /comparisons/run/{batch_id}` e verificar que:
  - não é criada nova comparação `batch`
  - o usuário é redirecionado para a área de importações
  - a orientação aponta para comparação por competência

## What was intentionally not changed

- Não foi removida a função de serviço `run_batch_comparison`, pois ela ainda é útil para leitura/migração de dados legados e para testes controlados.
- Não foi alterada a estrutura histórica já persistida em `comparison_runs`.
