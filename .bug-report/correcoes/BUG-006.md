# BUG-006

## Root cause

O aplicativo registra `SessionMiddleware` em `app/main.py`, e a implementação dessa middleware depende do pacote `itsdangerous`. O manifesto `requirements.txt` não declarava essa dependência, então um ambiente criado a partir dele podia falhar já no import inicial da aplicação.

## Files changed

- `requirements.txt`

## Exact fix applied

- Adicionada a dependência `itsdangerous>=2.2,<3.0` ao `requirements.txt`.

## Regression risk considered

Baixo. A mudança apenas alinha o manifesto com uma dependência já exigida pelo código em produção.

## How to validate

- Executar `.venv/bin/pip install -r requirements.txt`
- Executar `./.venv/bin/python -c "import app.main"`
- Subir a aplicação com `./run.sh` ou `./.venv/bin/uvicorn app.main:app`

## What was intentionally not changed

- Não foi removido `SessionMiddleware`, porque ele é necessário para o fluxo de mensagens flash já implementado.
- Não foram alteradas rotas, templates ou comportamento de sessão.
